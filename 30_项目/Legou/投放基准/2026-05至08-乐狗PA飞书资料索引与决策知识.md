# 2026-05 至 08 乐狗 PA 飞书资料索引与决策知识

## 文档用途

本文件不是会议原文汇编，而是乐狗 PA 工作的调用入口，用于回答：

- 一条 PA 是否真正通过测试，应该看什么数据。
- ROK、COD/SAMO 已验证过哪些方向，哪些判断已经变化。
- 新 PA 应该如何选型、制作、验收和复盘。
- 历史会议、管理表、方案和数据报表从哪里查。

涉及具体 ROAS 数据时，同时读取 [[2026-07-29-ROK-COD-SAMO-PA标准归因口径与落地方案]]。本文件中的内部信息默认不对外传播。

## 一、结论先行

1. **先确定评价对象，再谈达标。** 纯 PA、视频+PA、素材 Media 花费和 Creative Set 回收是不同层级，不能把不同层级的花费与收入拼成“单 PA ROAS”。
2. **视频+PA 跑出，只能证明组合可跑。** 2026-07-30 的会议已经明确：判断 PA 自身是否通过，应使用纯 PA 的消耗和成熟 ROI；视频+PA 不能证明 PA 独立通过。
3. **吸量不等于商业通过。** “灵能觉醒”曾因相对吸量被看好，但在 2026-07-30 的最新业务判定中未通过 T0/T1；MiniMart 也出现 Facebook 成本较好但 ROI 未过、AppLovin ROI 通过但成本优势不足的分化。
4. **ROK 当前更值得继续探索的是低理解成本的轻玩法入口。** 优先级较高的结构包括模拟经营后勤、资源生产与扩建、迷雾或地图展开、划线圈地和简单护送。历史纯战斗 PA 整体较弱，不宜因“更贴近 SLG”就默认有效。
5. **制作质量是实际瓶颈，不只是玩法选型。** 多次会议反复出现需求不清、美术对齐过晚、反馈不够明显、模型比例和动线有问题、脚本不够精确等问题。PA 应在 L0/L1 阶段尽早锁定玩法、镜头、反馈和美术基准。
6. **PA 进入产品新前期需要第二套证据。** 广告侧通过后，还要验证试玩行为、安装后留存、付费和关键行为承接，不能直接把广告吸量结论当作产品玩法结论。

## 四、当前统一决策口径

### 1. 评价对象

| 对象 | 可以回答 | 不可以回答 |
|---|---|---|
| Media素材花费 | 素材关联消耗和量级 | 单PA收入和ROAS |
| 单PA Creative Set | 纯PA投放单元是否回收 | PA相对无PA的因果增量 |
| 视频+PA Creative Set | 该组合是否可跑 | PA独立贡献 |
| 视频-only与视频+PA A/B | PA对固定视频的增量 | 跨市场、跨周期直接外推 |
| PA试玩行为 | 玩家是否理解并完成互动 | 安装后产品留存和付费是否成立 |

### 2. T0/T1的使用原则

- 2026-07-30 会议对原则的确认：T0看严格的纯PA消耗与ROI；T1看单渠道达到一定消耗并满足ROI或成本优势。
- 该会议出现“单渠道消耗5,000美元”“成本低约30%”的表述；2026-07-24 的项目标准记录则包含 ROK 8,000/50,000美元和25%成本优势等数字。
- 两组数字可能属于不同项目、不同版本或不同评价层级。**在负责人确认适用范围前，不用7月30日的通用讨论覆盖7月24日的项目标准。**
- T1存在“相对弱池中胜出”的假阳性风险。“猎鹿人”被用作提醒案例：在一批整体较弱的PA中相对跑得多，不等于达到绝对商业标准。

### 3. 建议保留的结论状态

`不可测`、`样本不足`、`量级未通过`、`回收未通过`、`组合通过`、`PA通过`。

所有复盘至少记录：项目、版本、市场、系统、渠道、测试周期、优化目标、纯PA或视频+PA、同层级消耗、成熟ROI、对照组和结论状态。

数据审计边界：已有 AppLovin 样本没有找到可用的基础版单PA测试单元，因此可以执行“未通过、暂不推进”的业务决定，但仍不能严谨归因出灵能觉醒PA自身的独立ROAS。

### 2. MiniMart方向

- 已测试4条视频和3条PA。
- Facebook侧有成本优势，但ROI未通过；AppLovin侧ROI通过，但成本优势不明显。
- “种田发家、制作木乃伊”更吸量；“废弃文明重建、金字塔建造”成本最低。
- 已知有视频素材达到T0，但不能据此说PA达到T0。
- PA混合视频表现较好，纯PA仍未通过；建议补Google测试并保持纯PA与组合分开看。
- 定制商店页、专属承接视频和产品前期改造，应在PA核心商业条件通过后再追加，避免过早增加成本。

### 3. ROK方向判断

- 护送模拟经营加轻战斗：纪要记录Google两周消耗约12,000，ROI一般。可研究“模拟经营做后勤”，不要只复制战斗表层。
- 划线圈地、自动出兵：理解成本低，可能触达新的轻策略用户，但要防止吸来只喜欢微操、与产品长线承接不匹配的人群。
- Top General类划线编队：纪要记录约15,000消耗、ROI约5.86且未形成规模，数字口径需回原文确认。
- 破坏解压、收集资源、文明重建：反馈直接，但冷兵器和ROK美术包装适配是难点。
- My Little Universe、Dreamdale、Royal Land式地图展开：与ROK迷雾探索、土地解锁、资源扩张的结构相容，适合继续做结构转译。
- 历史纯战斗PA整体表现弱。玩法贴近主产品不是充分条件，前三秒理解、即时反馈和轻用户可操作性更重要。

## 六、可复用的选型方法

### 1. 创意评分

现有评分模型的主要权重：

| 维度 | 权重 | 判断问题 |
|---|---:|---|
| 视觉理解 | 30% | 前3秒能否看懂目标、威胁和操作 |
| 交互爽感 | 25% | 操作是否立即产生明显结果 |
| 新鲜度 | 15% | 是否有区别于常见模板的传播点 |
| SLG映射 | 15% | 能否自然映射到建设、扩张、战斗或资源循环 |
| 经济循环 | 15% | 奖励能否反哺效率并形成持续成长 |

评分只能用于初筛，不能替代真实投放结果。

### 2. 模拟经营PA的基础循环

`直观动机 -> 核心操作解决问题 -> 获得资源 -> 提升效率 -> 解锁更大目标`

可复用原则：

- 动机优先选择市场验证过、日常可理解的需求，例如寒冷、饥饿、缺水、受伤、重建。
- 大反馈和小反馈交替，关键资源、升级和状态变化要夸张且可见。
- 尽量降低操作和规则理解成本，单摇杆或单一手势优先。
- 借鉴竞品时保留有效循环，替换动机、行动和包装，不直接照搬题材。
- 迭代时一次只验证一个主要变量，区分玩法改动、视觉换皮和数值调整。

### 3. 选型前必须回答

1. 用户前3秒看到了什么冲突或目标？
2. 第一次操作后有什么可见状态变化？
3. 30至60秒内能否完成一次完整循环？
4. 玩法吸引的人群与产品能承接的人群是否一致？
5. 这是验证PA商业效率，还是验证产品副玩法？两者需要什么不同数据？
6. 测试单元是否能区分纯PA和视频+PA？

## 七、制作与供应商管理经验

1. **脚本要精确到可验收。** 写清镜头、操作、路径、速度、资源变化、成功失败反馈、结束状态和关键参数。
2. **L0/L1先对齐核心。** 在投入完整3D和特效前，先验证玩法闭环、镜头、动线、模型比例和交互是否成立。
3. **美术不是最后换皮。** 对比度、饱和度、角色识别、资源图标、按钮状态和建筑升级反馈都会直接影响理解与点击。
4. **先冻结关键变量。** 版本变化、代码兼容、素材交付和需求反复会显著推高返工，应在开发前完成脚本和分镜确认。
5. **验收同时看广告与体验。** 除加载和兼容外，必须检查首个可操作时间、误触、卡死、反馈延迟、完成率和结束页衔接。
6. **优化先找最大问题。** 小改动经常无法超过积累过数据的原版；疲劳后可以测试明显换皮或大结构变化，但不能把多个变量一起改后再猜原因。

1. **固定PA实验登记。** 每个PA建立唯一ID，保存版本、玩法原型、供应商、纯PA/组合、投放条件、素材成员历史和最终状态。
2. **统一报表。** 同一张表分开显示Media素材花费、单PA Set、视频+PA Set和固定视频A/B，不再混用分母。
3. **优先补关键实验。** 对MiniMart及下一批ROK候选建立纯PA Set，并设置固定视频的video-only、video+PA对照。
4. **建立产品承接关卡。** 只有广告商业结果通过后，再看试玩行为和安装后D1/D7、付费、关键行为，决定是否进入新前期。
5. **按绝对标准停损。** 相对同批素材更好但未达到最低量级或回收的项目，不因“池内第一”继续追加高成本定制。
6. **下一轮优先选型。** ROK优先验证模拟经营后勤、资源扩建/地图展开、低门槛划线圈地；纯战斗方向除非有明显的新反馈结构，否则降低优先级。
