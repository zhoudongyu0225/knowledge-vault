# 龙虾游戏推荐：小游戏生态与发行观察

## 结论先行

“龙虾游戏推荐”最适合当作**小游戏生态雷达和发行供需观察源**，而不是产品数据源或买量 Benchmark。

它的主要价值有三类：

1. **产品雷达**：长期观察微信小游戏、休闲玩法、IAP/IAA、融合品类和头部厂商动作。
2. **生态判断**：把平台政策、用户变化、团队能力、发行需求和产品供给放在一起看。
3. **发行视角**：关注一个方向能不能买量、谁适合做、应该在哪个平台做、如何获得第一批用户，以及能否长期经营。

对当前工作的价值高于普通新品推荐号，但使用时必须补两层验证：

- 用最新平台报告核验时效性。
- 用项目自己的 CPI、留存、付费、广告 ARPU、ROI 和 LTV 核验商业成立。

## 内容演化

### 1. 2019-2020：小游戏发现与行业连接

早期内容主要解决两个问题：

- 市面上有哪些值得体验的微信小游戏。
- 研发、发行、平台和服务方如何找到彼此。

这个阶段积累的是产品样本和行业关系，不是严格的数据研究。早期月度收录可以用于回看玩法变迁，但不值得把大量历史产品名重复搬进知识库。

### 2. 2024：从推荐产品转向解释行业

2024 年的文章开始稳定讨论：

- 大厂为什么有钱却找不到合适产品。
- 中型团队为什么速度比不过 IAA、质量比不过大厂。
- 小团队如何先获得现金流，再建立买量和发行能力。
- IAA、IAP、混合变现如何影响立项。
- 平台政策、自然量和多平台分发如何影响回收。
- 为什么热门 Like 在头部厂商入场后不再适合普通团队追逐。

这部分是本专题最值得长期保留的内容。

### 3. 2025：出海、用户与立项信号

2025 年的公开观点把观察范围扩展到：

- 中国厂商与越南、土耳其等 T2/T3 休闲研发团队的竞争。
- 海外素材和 TikTok 热点反向影响国内小游戏立项。
- 休闲 PVP 可能成为海外发行关注方向。
- 女性泛用户、PC 端、IP 和视频号成为微信小游戏的机会假设。
- 大厂更应关注平台政策，小团队先理解玩法、产品和生态。

这些是方向性信号，不是已经得到数据验证的结论。

### 4. 2026：方法开始产品化

2026 年公开课程提纲将 IAA 小游戏拆成：

```text
商业模式
-> 创意来源
-> 成本与商业化约束
-> 品类和用户
-> 留存与广告设计
-> 最小立项测试
```

公开页面没有课程正文，因此只确认其方法结构，不推断具体阈值或案例结论。

## 可复用的核心方法

### 1. 用五个变量判断小游戏机会

龙虾内容中反复出现的底层结构可以还原为：

```text
平台机制
x 用户结构
x 产品形态
x 商业模型
x 团队能力
= 当前团队可执行的机会
```

只看到热门玩法不够。相同玩法在不同平台、不同用户、不同变现方式和不同团队手里，结果可能完全不同。

#### 平台机制

关注平台流量入口、激励政策、审核、广告产品和复访能力。平台政策能改变短期单位经济性，但政策红利会过期。

#### 用户结构

先回答用户是谁、在哪里、为什么点开、是否已有同类游戏沉没成本。小游戏里的泛用户不能直接按传统 APP 核心玩家设计。

#### 产品形态

玩法第一眼是否看懂，内容深度能否承接 D7/D30 以后，轻量入口和长期系统是否一致。

#### 商业模型

IAA、IAP、混合变现对留存、广告频次、付费深度、买量目标和回收周期的要求不同，不能上线后再补商业化。

#### 团队能力

团队擅长快速试错、内容长线、数值商业化、美术包装、素材生产还是渠道运营，决定应该进入哪种赛道。

### 2. 不同体量团队不能使用同一套立项逻辑

| 团队 | 更适合的打法 | 主要风险 |
|---|---|---|
| 大厂/大发行 | 平台政策、IP、长线内容、多平台、投资或深度合作 | 资金和 APP 发行资源未必适配小游戏创意团队 |
| 中型团队 | 深耕细分品类、做可持续内容与商业化、避免追头部 Like | 研发效率不如轻量团队，品质和投放又难压过大厂 |
| 小团队 | 先做定制、素材、试玩或小而美产品形成现金流，再补买量能力 | 不敢花钱导致无法验证，或盲目扩张导致现金流断裂 |

对发行制作人的含义是：项目评审不能只问产品好不好，还要问**这个团队是不是实现它的合适主体**。

### 3. “自然量”也有成本

龙虾参与的圆桌将自然量重新解释为：

```text
没有直接按 CPM/CPC 购买
不等于没有成本
```

搜索优化、视频号、达人、游戏圈、社区、社交传播和跨平台联动，都需要内容、运营、人力和时间。

发行评估时应把获量成本拆成：

| 成本 | 示例 |
|---|---|
| 媒体成本 | 信息流、直播、达人合作、广告金 |
| 内容成本 | 素材、直播内容、社区内容、活动 |
| 运营成本 | 搜索优化、游戏圈、社群、跨平台维护 |
| 机会成本 | 团队为争取平台红利放弃的其它工作 |

不能把“自然量”记作零成本，也不能把一次平台推荐当成稳定供量。

### 4. 产品推荐要转成“模式识别”

公众号会出现大量产品和厂商名，但长期有用的不是名单，而是下面这组字段：

```text
产品/厂商
平台
目标用户
核心动作
融合结构
吸量入口
变现方式
内容深度
团队能力
已验证结果
```

产品名称继续由 [[王董的新游戏-产品去重与分类库]] 去重维护。本专题只保留能解释平台、团队或商业模式变化的代表案例，避免重复建产品库。

### 5. 素材是立项信号，不是立项结论

2025H1 的原文观察指出，海外广告素材和 TikTok 热门内容正在影响国内小游戏立项。

可用方式：

1. 用素材发现新的情绪、题材、冲突和用户兴趣。
2. 抽取可迁移的核心动作与视觉反馈。
3. 做低成本创意或试玩验证。
4. 再用产品留存、商业化和供量验证立项。

不可用方式：

- 只因为素材爆量就认为产品 LTV 成立。
- 把一次热点当成长线品类。
- 复制素材表面表现，不理解其用户情绪。

### 6. “慢钱”需要单独的经营模型

2024 年度原文最值得保留的判断是：市场从单一追逐 Like 和买量，转向多种规模、类型和变现模式并存，部分慢回收项目开始获得合理回报。

这与 2026H1 的内部资料能够相互印证：

- 微信在投产品增长放缓，但素材仍增长。
- 用户打开次数下降、单次使用时长增长。
- 竞争重点从批量上新转向单产品经营、素材密度和长线内容。

详见 [[微信小游戏买量-资料索引与交叉判断]]。

| 长期主义 | 慢钱、细分赛道和长期运营的重要性上升 | 设计长回收与长内容产品模型 | 必须结合现金流和预测误差 |

## 与作者观点的分歧和待验证项

### 1. “倍数倍率可以吸收留存和自然量”只适合粗筛

2024 文章中有一种简化思路：自然量、留存最终会反映在整体 ROI 或回收倍数中，因此买量型产品可先看倍数。

我的判断：

- **用于第一轮商业粗筛是合理的**：一个统一的回收指标可以快速淘汰明显不成立的项目。
- **用于扩量和归因是不够的**：同样的 ROI 可能来自高留存、偶发大 R、活动、自然量、渠道返点或短期素材红利，未来扩量反应完全不同。
- **对 ROK/COD 尤其不能只看整体倍数**：必须拆 cohort、渠道、地区、系统、自然/广告用户、活动和大 R 扰动。

正确做法：

```text
第一层：整体 ROI / 回收倍数判断能不能继续
第二层：留存、付费、广告 ARPU、渠道和自然量判断为什么
第三层：小规模扩量验证边际是否稳定
```

### 2. “女性用户是唯一红利”证据不足

2025 圆桌中，虾哥把女性用户称为国内小游戏最明显的机会群体。这个方向值得重视，但“唯一”过强。

验证方式：

- 分性别比较 CTR、CVR、D1/D7 留存、付费率、广告 ARPU 和 LTV。
- 对传统男性向 SLG/卡牌测试角色、冲突、经营、社交等不同入口。
- 检查女性新增是否来自平台结构变化，还是个别头部产品。

### 3. T2/T3 成本优势不等于竞争优势

越南、土耳其团队的成本和休闲研发工业化值得长期跟踪，但需要补：

- 爆款数量和持续成功率。
- 本地人才成本变化。
- 素材、产品、商业化和发行分别由谁完成。
- 是否依赖 Rollic 等发行体系。
- 全球化扩张后的内容和运营能力。

### 4. 平台政策与行业数字必须按日期失效

2024-2025 文章中的广告金、平台新增、日耗、流量入口和扶持政策，只能作为当时的生态证据。

## 对当前工作的实际帮助

### 1. 建立发行选品的前置检查

在传统产品评审之外，增加五个问题：

```text
这个产品为什么适合当前平台？
它获取的是传统玩家还是泛用户？
当前团队的真正优势是什么？
商业化从第几天、哪个行为开始成立？
即使首轮素材成功，D30以后靠什么留下用户？
```

### 2. 改进签约和合作匹配

龙虾对行业供需的观察提醒：发行、研发、平台和服务商数量并不少，缺的是具体问题与具体能力的匹配。

以后寻找合作方时，不问泛化的“有没有好团队”，而是给出：

```text
品类与平台
目标用户
团队规模
已完成阶段
缺失能力
预算与时间
需要的合作方式
成功标准
```

这比依赖广泛人脉更容易得到有效答案。

### 3. 把创意趋势接入产品决策

海外素材、TikTok 热点和小游戏爆款可以共同形成早期信号，但分成三层：

| 层级 | 要回答的问题 |
|---|---|
| 素材层 | 什么情绪、动作和视觉反馈能吸引点击？ |
| 产品层 | 点击后能否形成可重复的核心循环？ |
| 生意层 | 留存、广告或付费能否覆盖获量和内容成本？ |

这适合用于 ROK/COD 的轻玩法入口和试玩广告探索，但只能借用表达结构，不能套小游戏数据。

### 4. 用当前数据修正作者的历史判断

截至 2026H1：

- 微信小游戏更接近存量深耕，产品数增速低于素材增速。
- 抖音仍处于产品与素材供给扩张。
- AI 素材已经进入主生产线，但没有证明 ROI 更高。
- 轻休闲占全量供给，中重度数值产品更集中在热投样本。

因此，龙虾在 2024 年提出的“多元化、慢钱、长线运营”仍有解释力；具体平台机会则必须切换到 2026 数据。

## 建议的调用方式

适合问：

```text
调用龙虾专题，判断这个小游戏方向的平台、用户、商业模式和团队是否匹配。
```

```text
结合龙虾专题和2026小游戏数据，判断这个热点是平台红利、素材红利还是产品机会。
```

```text
用龙虾的团队供需框架，分析这个项目应该自研、签约、投资还是只做发行服务。
```

```text
把这个海外热门素材拆成小游戏立项信号，但不要把素材表现当成产品成立。
```

不适合直接问：

```text
按照龙虾文章给我一个当前行业CPI或ROI Benchmark。
```

## 持续关注信号

- 微信、抖音、快手、PC 小游戏的政策和流量入口变化。
- IAA、IAP、混合变现产品的供给结构。
- 新玩法是否只有素材热度，还是出现稳定长线产品。
- 女性、中老年和非传统玩家是否有项目级数据验证。
- 越南、土耳其等团队的产品成功率与发行合作方式。
- 休闲 PVP 是否出现可持续供量和留存案例。
- 大厂投资、收购或深度绑定小游戏团队的实际案例。
