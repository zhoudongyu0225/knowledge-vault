# 新手流程与活动节奏案例：WhiteOut 与永远的蔚蓝星球

## 一句话结论

WhiteOut 的早期体验不是把系统逐项讲给玩家，而是用生存危机推动一条“剧情动机、资源目标、建造操作、战斗卡点、状态恢复、章节奖励”的依赖链；《永远的蔚蓝星球》活动图则显示，玩家价值来自识别活动重叠并延迟不可逆的资源消耗。

## 新手设计结构

### 1. 危机不是背景，而是行为动机

```text
寒冷和暴风雪
-> 需要木材和火炉
-> 需要食物和住所
-> 需要生产设施和幸存者
-> 需要更高等级熔炉
```

玩家不是因为教程说“请升级建筑”而升级，而是因为世界状态给出了明确理由。

### 2. 大目标和短目标同时存在

- 大熔炉控制城镇大阶段。
- 建筑内部用床、书桌、工位、病床等 2/4/6/8/10 级制造短目标。
- 新幸存者增加劳动力需求，使人口、生产和建筑互相推动。

### 3. 经济线和战斗线互锁

```text
建模具需要钢材
-> 钢材来自探险
-> 探险需要英雄等级、升星和编队
-> 英雄成长又引出招募、碎片和活动
```

这能防止玩家只停留在单一城建循环，也为新的成长和商业化系统提供自然入口。

### 4. 强制教学逐步升级

流程中可见：

- 提示钻石加速。
- 强制使用加速道具。
- 提示升级战斗英雄。
- 强制教学自动技能和战斗加速。
- 强制修复灯塔并进入出征。

设计上先展示价值，再要求使用，随后在真实卡点中复用。文件没有价格和付费数据，只能确认转化触点，不能评价付费深度。

### 5. 叙事节点承担系统切换

- 爷爷去世完成“求生”动机建立。
- 商队出现引出英雄。
- 钢材卡点把城建引向探险。
- 灯塔和迷雾把内部建设引向外部世界。

剧情不是独立内容线，而是系统切换的解释器。

## 活动节奏的真正价值

### 1. 重叠窗口创造资源期权

同一个抽卡、主线或成长动作可能同时为两个活动计分。提前消耗会失去未来重叠收益，因此“暂时不做”可能比“立即完成”价值更高。

### 2. 玩家攻略暴露了产品的隐形规则

官方日历告诉玩家活动什么时候开，高手攻略会补充：

- 哪些资源要留。
- 留多少。
- 哪些任务不要立即完成。
- 哪些礼包只在重叠窗口购买。
- 哪个阶段停止推进。

这些信息适合反推活动经济和玩家决策压力。

### 3. 活动表不应只有日期

更有用的活动运营表应包含：

| 字段 | 用途 |
|---|---|
| 日期和持续时间 | 看节奏 |
| 消耗资源 | 看资源冲突 |
| 产出和奖励 | 看激励 |
| 重叠活动 | 看协同 |
| 储备阈值 | 看玩家准备成本 |
| 明确不做项 | 看延迟选择 |
| 付费入口 | 看商业化 |
| 版本和区服 | 防止跨版本误用 |

## 可复用的分析模板

### 新手流程七列法

```text
相对时间
剧情或世界状态
玩家操作
系统解锁
资源门槛
奖励
商业化触点
```

### 系统依赖图

先区分：

- 主轴：必须完成才能继续。
- 并行准备：可提前积累的资源或战力。
- 回环任务：完成后回到主循环。
- 软卡点：等待、资源或效率不足。
- 硬卡点：系统强制要求。

不要把白板的上下位置直接当作严格时间顺序。

### 活动重叠表

```text
活动 A 的得分行为
活动 B 的得分行为
重叠日期
可提前储备的资源
不可逆动作
延迟成本
重叠收益
```

## 对创意的启发

WhiteOut 序章具有清晰的短视频结构：

```text
极寒下降
-> 找木材
-> 点火
-> 温度恢复
```

冲突、操作、状态变化和反馈都能在短时间内看懂。创意可借鉴这个信息结构，不需要复制完整 SLG 系统或题材。

## 对个人能力的价值

1. 学会把复杂系统还原成依赖关系，而不是只记功能列表。
2. 识别“什么时候不行动更有价值”，提高延迟决策和资源配置能力。
3. 区分官方规则、玩家策略和分析者推断。
4. 用时间线、依赖图和重叠表三种视角看同一问题。
5. 研究一个产品时，同时理解设计者如何引导和熟练玩家如何反制、优化。
