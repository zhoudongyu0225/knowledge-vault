# 微信群摘录收件箱

## 为什么是这个方式

微信 4.x 的本地聊天数据库（`db_storage/message/*.db`）经 SQLCipher 加密，
2026-08-03 实测文件头非 `SQLite format 3`，属加密态。解密需从运行中的微信进程
内存 dump 密钥，属逆向行为，有封号与合规风险，收益不成比例，因此不采用。

个人微信也没有官方消息 API。所以群内容采集走「人工投递 + 自动整理」：
你只负责把值得留存的内容丢进来，提炼、分类、归档由周度任务完成。

## 怎么用

1. 在群里选中要保留的消息，复制或合并转发。
2. 在本目录新建一个文件，命名 `YYYY-MM-DD-群名-主题.md`，把内容粘进去。
   - 不必整理格式，原样粘贴即可。
   - 截图放 `90_附件/`，在文件里用相对路径引用。
3. 文件顶部尽量写一行来源，例如 `来源：XX交流群 / 2026-08-03 / 讨论买量成本`。
   写不写都行，写了归档更准。

## 周度任务会做什么

每周日 20:00 自动扫描本目录，对每个待处理文件：

- 提炼结论、影响、后续动作，按 `_模板/聊天记录.md` 结构整理。
- 按 `_索引/分类规则.md` 路由到正式目录（游戏发行进 `40_资料库/游戏发行与广告/`，
  个人理财进 `40_资料库/个人收藏/`，项目相关进 `30_项目/`）。
- 归档后在本目录保留原文件并在文首标记 `status: processed`，不自动删除。

## 边界

- 群聊内容默认 `visibility: private`。
- 只沉淀观点、判断、数据口径和行动项，不保留可识别个人身份的信息和大段原文。
- 付费群内容只保留方法与结论，不做原文搬运。
